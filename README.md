# Plecak Helenki - PWA (Offline Web App)

Gotowa paczka do wrzucenia na GitHub Pages:
1. Utwórz nowe repozytorium na GitHubie (np. `plecak-helenki`).
2. Wgraj wszystkie wypakowane pliki z tego archiwum bezpośrednio do głównego folderu repozytorium (`index.html`, `manifest.json`, `sw.js`, ikony `.png`).
3. W ustawieniach repozytorium wejdź w **Settings -> Pages**, wybierz gałąź `main` (folder `/root`) i kliknij **Save**.
4. Otwórz wygenerowany link na telefonie Helenki:
   - **Android (Chrome):** Kliknij menu (3 kropki) -> **Dodaj do ekranu głównego / Zainstaluj aplikację**.
   - **iPhone (Safari):** Kliknij ikonę **Udostępnij** na dole -> **Do ekranu początkowego**.
